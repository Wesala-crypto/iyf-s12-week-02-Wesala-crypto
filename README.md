# IYF Season 12 — Week 2: CSS Mastery

Welcome to my Week 2 project for the **IYF WeCan Academy Season 12 Computer Programming course**.

This project focuses on mastering CSS fundamentals, responsive layouts, and accessible web design.

## Live Demo

🔗 **Live Website:** [View My Website](https://wesala-crypto.github.io/iyf-s12-week-01--Wesala-crypto-/)

## About the Project

This project is a multi-page personal website built using HTML5 and CSS3. It introduces me, showcases my skills and projects, and provides a contact form.

The goal is to apply CSS styling techniques to create a consistent, accessible, and responsive website.

## Pages

- **Home:** Introduction and hobbies.
- **About:** Background, skills, and goals.
- **Projects:** A showcase of my web development and graphic design projects.
- **Contact:** A form for visitors who want to get in touch.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media queries
- CSS custom properties (variables)
- Google Fonts — Libre Baskerville
- Git and GitHub

## CSS Features

- CSS reset using `box-sizing: border-box`.
- Reusable colour and typography variables.
- Flexbox navigation.
- Responsive CSS Grid for project cards.
- Mobile-first design with media queries.
- Hover and keyboard-focus states for links and buttons.
- Consistent styling across all four pages.
- Form styling and input validation.
- Box-model practice.

## Responsive Design

The website is designed to adapt to different screen sizes.

| Screen size | Projects grid |
|---|---|
| Phone | 1 column |
| Tablet | 2 columns |
| Desktop | 3 columns |

The deployed website should be tested at **320px, 768px, 1024px, and 1440px** to verify that the layout works without horizontal scrolling.
